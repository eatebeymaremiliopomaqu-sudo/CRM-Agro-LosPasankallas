CRM-AGRO · GRUPO [NÚMERO]
=========================
CRM web modular y de bajo costo para fincas pequeñas (frutas, hortalizas y vivero):
control técnico de campo, trazabilidad con QR, trabajadores, inventarios, ventas,
vivero y finanzas, con WhatsApp y un agente de IA que registra datos con
confirmación previa (SI/NO) y NUNCA recomienda dosis de agroquímicos.
Todos los datos son FICTICIOS (Finca Los Molles, Comarapa).

CÓMO ARRANCAR EN LOCAL (Windows, PowerShell, Node.js 20 o superior)
  IMPORTANTE: la ruta de la carpeta NO puede contener "#" (renombrar CRM_Agro_Grupo##).
  Terminal 1 (backend, http://localhost:3000 · Swagger /api/docs):
    cd codigo\backend
    Copy-Item .env.example .env
    npm install
    npm install-scripts approve prisma @prisma/client @prisma/engines esbuild
    npm rebuild
    npx prisma generate
    npx prisma db push
    npm run db:seed
    npm run dev
  Terminal 2 (frontend, http://localhost:5173):
    cd codigo\frontend
    npm install
    npm install-scripts approve esbuild      (solo si npm lo pide)
    npm rebuild
    npm run dev
  Liberar un puerto: netstat -ano | findstr :3000   y luego   taskkill /PID <número> /F

CÓMO CONECTAR WHATSAPP (detalle: codigo/docs/WHATSAPP_TWILIO.md)
  1. Crear cuenta en twilio.com y abrir Messaging > Try it out > Send a WhatsApp message.
  2. Desde el celular enviar "join <palabra-palabra>" al +1 415 523 8886.
  3. Poner el número del celular (591XXXXXXXX) en un usuario de la finca (Configuración > Usuarios).
  4. Publicar el backend: cloudflared tunnel --url http://localhost:3000  (o usar Render).
  5. En Twilio, "When a message comes in": https://<url>/api/webhooks/twilio (POST).
  6. En codigo/backend/.env: WHATSAPP_PROVIDER=twilio, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN,
     TWILIO_WHATSAPP_FROM=whatsapp:+14155238886, TWILIO_WEBHOOK_URL=<la misma URL>. Reiniciar.
  7. Escribir "ayuda" al Sandbox. Sin credenciales todo funciona en modo simulado.
