CRM-AGRO · GRUPO LOS PASANKALLAS
================================
CRM web modular y de bajo costo para fincas pequeñas (frutas, hortalizas y vivero):
control técnico de campo, trazabilidad con QR, trabajadores, inventarios, ventas,
vivero y finanzas, con WhatsApp y un agente de IA que registra datos con
confirmación previa (SI/NO) y NUNCA recomienda dosis de agroquímicos.
Todos los datos de la finca son FICTICIOS (Finca Los Molles, Comarapa).

CÓMO ARRANCAR EN LOCAL (Windows, PowerShell, Node.js 20 o superior)
  IMPORTANTE: la ruta de la carpeta NO puede contener el carácter numeral (Vite falla).
  Terminal 1 (backend, http://localhost:3000 · Swagger /api/docs):
    cd codigo\backend
    Copy-Item .env.example .env
    npm install
    npm install-scripts approve prisma @prisma/client @prisma/engines esbuild
    npm rebuild
    npx prisma generate
    npx prisma db push
    npm run db:seed
    npm run dev
  Terminal 2 (frontend, http://localhost:5173):
    cd codigo\frontend
    npm install
    npm install-scripts approve esbuild      (solo si npm lo pide)
    npm rebuild
    npm run dev
  Liberar un puerto: netstat -ano | findstr :3000   y luego   taskkill /PID <número> /F

CÓMO CONECTAR WHATSAPP · META CLOUD API (detalle: codigo/docs/WHATSAPP_META.md)
  Se usa Meta y no Twilio porque Twilio exige verificar la cuenta por SMS y no envía SMS a
  Bolivia; Meta envía el código de verificación por WhatsApp (DECISIONES.md, ADR-022).
  1. developers.facebook.com/apps > Crear app > caso de uso "Conectarte con los clientes a
     través de WhatsApp" (tipo Empresa/Business).
  2. WhatsApp > Configuración de la API > "Para" > agregar el celular (+591) y verificarlo con
     el código que llega por WhatsApp. Pulsar "Enviar mensaje" y responder "hola".
  3. En codigo/backend/.env: WHATSAPP_PROVIDER=meta, WHATSAPP_TOKEN (token temporal),
     WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_APP_SECRET (Configuración de la app > Básica),
     WHATSAPP_VERIFY_TOKEN (inventado) y DEMO_WHATSAPP_ENCARGADO (el celular); npm run db:seed.
  4. Publicar el backend: cloudflared tunnel --url http://localhost:3000  (o usar Render).
  5. WhatsApp > Configuración > Webhook: https://<url>/api/webhooks/whatsapp + el token de
     verificación; en "Campos del webhook" suscribir "messages".
  6. Escribir "ayuda" al número de prueba de Meta. Sin credenciales todo funciona en modo simulado.
