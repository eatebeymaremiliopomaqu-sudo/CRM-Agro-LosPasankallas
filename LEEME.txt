CRM-AGRO · GRUPO ##
===================
CRM web modular y de bajo costo para fincas pequeñas: control técnico de campo,
trazabilidad con QR y gestión de trabajadores, con WhatsApp y un agente de IA que
registra datos con confirmación previa y NO recomienda dosis de agroquímicos.
Todos los datos son FICTICIOS.

MÓDULOS (M0-M7)
  M0: Núcleo (login, roles PROPIETARIO/ENCARGADO/TRABAJADOR, módulos activables)
  M1: Lotes y cultivos (campos en mapa, campañas agrícolas)
  M2: Control técnico de campo (labores, aplicaciones, observaciones)
  M3: Trazabilidad (lotes de cosecha con QR)
  M4: Trabajadores (personal, asistencias, jornales)
  M5: Ventas (EN DESARROLLO - clientes con consentimiento WhatsApp)
  M6: Vivero (EN DESARROLLO - almácigos y plantines)
  M7: Reportes (EN DESARROLLO - dashboards)

NOTA SOBRE NOMENCLATURA
  - "Lote" = campo/parcela de la finca (M1)
  - "Lote de cosecha" = producto cosechado con código QR (M3)
  - "Siembra" → "Campaña" en la base de datos
  - Rutas: /api/parcelas → /api/lotes

EJECUTAR EN LOCAL (Node.js 20+)
  cd codigo/backend   && cp .env.example .env && npm install
                      (si hay problemas: npm install-scripts approve)
                      && npx prisma db push && npm run db:seed && npm run dev
  cd codigo/frontend  && npm install && npm run dev     -> http://localhost:5173

PRUEBAS
  cd codigo/backend  && npm run test:cov   (91 pruebas unitarias + cobertura)
  cd codigo/backend  && npm run test:int   (integración; requiere BD con seed)
  cd codigo/frontend && npm test           (Vitest)
